# SpendWise Dashboard - Week 6

## Project Description
SpendWise is a simple budget dashboard that helps users track income and expenses. Users can add income, add expenses, see total expenses, balance, and budget status (Within Budget, Warning, Over Budget) in real time. A simple budget tracker built with HTML, CSS and JavaScript.

## Features
- Enter monthly income
- Add expenses with name and amount
- Uses Array to store expenses
- Uses Loop to calculate total
- Uses addEventListener for button click
- Uses DOM to show list and result
- Uses if/else to check budget status: Over Budget, Exact, Warning, Within Budget

## Deployment Process Summary
1. Created a public GitHub repository and pushed all project files.
2. Logged into Netlify and connected GitHub.
3. Imported the repository spendwise-dashboard-web-week6.
4. Deployed with default settings (Publish directory: . / Build command: none).
5. Changed the Netlify site name to a meaningful name.
6. Tested the live site on mobile and desktop.

## Challenges Encountered During Deployment
- No internet connection caused rename and deploy to fail at first.
- Finding the correct Settings / Rename page on mobile GitHub app.
- Waiting for Netlify to finish the first deploy.
